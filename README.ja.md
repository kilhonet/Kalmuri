# Kalmuri

**フルスクリーン・領域・ウィンドウ・ウェブページ全体をホットキー 1 つでキャプチャーし、画面を MP4 動画で録画できる Windows 用の無料キャプチャーソフト。**

## 概要

Kalmuri は、何をキャプチャーするか(**キャプチャー**)とどう残すか(**保存形式**)の 2 つを選んでおけば、あとは `PrintScreen` を 1 回押すだけでキャプチャーが終わるソフトです。キャプチャーのたびにウィンドウを開いたりファイル名を入力したりする必要はなく、結果は保存フォルダに `K-001.png`、`K-002.png` … の順にたまっていきます。

画面全体、いつも同じ位置の領域、マウスでドラッグした部分、今使っているウィンドウ、ウィンドウ内のボタン 1 つ、スクロールの長いウェブページ全体までキャプチャーできます。同じホットキーで画面を MP4 動画で録画したり、画面の色コードを取り出したり、画像内の文字をテキストにしたりもできます。

ウィンドウを閉じても通知領域(タスクトレイ)で動き続けるので、一度起動しておけばいつでもホットキーですぐにキャプチャーできます。

## 主な機能

- **7 種類のキャプチャー範囲** — フルスクリーン、指定した領域、ドラッグした範囲、アクティブウィンドウ、ウィンドウコントロール、ウェブページ全体、カラー抽出。
- **多彩な保存形式** — PNG · JPG · GIF · BMP · WebP ファイル、MP4 動画、文字認識(TXT)、クリップボード、画像共有、プリンター、画面に浮かべる(フローティング)。
- **画面録画** — フルスクリーンまたは指定した領域を MP4 で録画し、PC で鳴っている音も一緒に録音できます。
- **ウェブページ全体のキャプチャー** — Edge · Chrome で開いたページを、スクロールの最後まで 1 枚の画像に保存します。
- **文字認識(OCR)** — キャプチャーした画面の文字をテキストファイルに保存します。
- **カラー抽出** — カーソル下の色を HEX · RGB · Web · TColor 形式でコピーします。
- **キャプチャー画像の共有** — キャプチャーをウェブにアップロードし、すぐに開いてアドレスを共有できます。
- **フローティング** — キャプチャーした画像をその場所に常に手前で表示し、参考にできます。
- **キーボードで領域を調整** — 方向キー · `Ctrl`+方向キー · `Shift`+方向キーで、領域を 1 ピクセル単位まで合わせられます。
- **便利な設定** — ホットキーの変更、ファイル名の形式(連番 · 日付時刻)、キャプチャー音、マウスカーソルを含める、システム起動時に実行。
- **8 言語** — 韓国語 · 英語 · 日本語 · 中国語 · ロシア語 · イタリア語 · フランス語 · スペイン語。

## 使い方

### はじめての使い方

1. Kalmuri を起動すると小さなウィンドウが開き、通知領域に Kalmuri のアイコンが表示されます。
2. **キャプチャー** で何をキャプチャーするかを選びます。最初は **フルスクリーン** です。
3. **保存形式** でどう残すかを選びます。最初は **PNG** です。JPG · WebP を選ぶと横に画質欄が、TXT を選ぶと認識言語欄が表示されます。
4. `PrintScreen` を押します。シャッター音とともにキャプチャーされ、保存フォルダ(最初はデスクトップ)に `K-001.png` として保存されます。
5. **開いたフォルダ** を押すと保存フォルダが開き、結果をすぐに確認できます。
6. ウィンドウを閉じても Kalmuri はタスクトレイで動き続けます。トレイアイコンを押すとウィンドウが再び表示され、ウィンドウまたはトレイアイコンを **右クリック** すると設定メニューが出ます。

### こんなときは

**画面全体を一度にキャプチャーする**
**キャプチャー** を **フルスクリーン** にしたまま `PrintScreen` を押すだけです。ウィンドウを開かなくても、Kalmuri がタスクトレイにあればどこからでもキャプチャーできます。

**いつも同じ位置・同じサイズでキャプチャーする**
**地域** を選ぶと、赤く点滅する枠ウィンドウが現れます。枠をドラッグして動かし、端をドラッグしてサイズを合わせてから `PrintScreen` を押すと、枠の **内側** だけがキャプチャーされます。枠の上部には現在のサイズ(例: `480x360`)が表示され、枠の位置とサイズは記憶されて次回もそのままです。右上の X を押すと枠が閉じて **フルスクリーン** に戻ります。

**領域をピクセル単位で正確に合わせる**
領域の枠ウィンドウをクリックしてからキーボードを使います。方向キーは 1 ピクセルずつ **移動**、`Ctrl`+方向キーは 10 ピクセルずつ、`Shift`+方向キーは 1 ピクセルずつ **サイズ** を変えます。マウスでおおまかに合わせてから、キーボードで仕上げると便利です。

**よく使うサイズを保存しておく**
領域の枠を右クリックすると `320x240` · `640x480` · `720x480` などのサイズ一覧が出て、ワンクリックで切り替えられます。一覧のサイズは **設定する** で **ユーザー定義 #1 ~ #3** の幅・高さを入力して変更します。**現状** に数値を入れて **適用する** を押すと、今の領域をそのサイズに合わせます。同じメニューの **隠す** は枠を一時的に隠します。

**必要な部分だけをマウスで選んでキャプチャーする**
**ドラッグ** を選んで `PrintScreen` を押すと、画面が止まって暗くなります。キャプチャーしたい部分をマウスでドラッグして離すと、その部分だけが保存されます。やめるときは `Esc` を押します。画面が止まった瞬間をキャプチャーするので、開いたメニューや一瞬だけ出る通知も写せます。

**今使っているウィンドウだけをキャプチャーする**
**アクティブウィンドウ** を選び、キャプチャーしたいウィンドウをクリックして前面に出してから `PrintScreen` を押します。デスクトップやほかのウィンドウは入らず、そのウィンドウだけが保存されます。

**ウィンドウ内のボタン・パネル 1 つだけをキャプチャーする**
**ウィンドウコントロール** を選ぶと、マウスカーソルの下の要素に点線の枠がついてきます。目的のボタン・入力欄・パネルにカーソルを合わせて `PrintScreen` を押すと、枠の中の要素だけが保存されます。マニュアルや問い合わせに特定の部分だけを切り取って貼るときに便利です。

**長いウェブページを最後まで 1 枚に**
**ウェブブラウザ** を選ぶと、Kalmuri が Edge(なければ Chrome)のウィンドウを別に開きます。そのウィンドウで目的のページを開いて `PrintScreen` を押すと、スクロールしないと見えない下の部分までページ全体が 1 枚の画像として保存されます。タブが複数あるときは、今見ているタブをキャプチャーします。そのブラウザのウィンドウを閉じると **フルスクリーン** に戻ります。Windows 8 以降で、Edge か Chrome がインストールされている必要があります。

**画面の色コードを調べる**
**カラー抽出** を選ぶと、ウィンドウにマウスカーソル下の色とコードがリアルタイムで表示されます。目的の場所にカーソルを置いて `PrintScreen` を押すと、その色が一覧の一番上に追加され、クリップボードにもコピーされます。一覧を右クリック → **形式** でコピー形式を **HEX**(`FF9933`) · **RGB**(`255, 153, 51`) · **Web**(`#FF9933`) · **TColor**(`$003399FF`) から選び、同じメニューで一覧の項目をコピー・削除できます。

**画面を動画で録画する**
**保存形式** を **MP4** にして `PrintScreen` を押すと録画が始まり、ウィンドウに録画中であることと経過時間が表示されます。もう一度 `PrintScreen` を押すと録画が止まり、MP4 ファイルが保存されます。録画は **フルスクリーン** と **地域** で使え、領域を録画している間は枠の上に `[REC]` と時間が表示され、領域が動かないよう固定されます。

**PC で鳴っている音まで録画する**
**録画設定 → サウンドを含める** をオンにすると、映像と一緒に PC で再生されている音(動画・ゲーム・通知音)を録音します。講義や動画再生の画面を録画するときにオンにしてください。

**録画をつけたまま席を外すとき**
**録画設定 → 録画時間の制限** を **30分** · **1時間** · **2時間** · **4時間** のどれかにしておくと、その時間が過ぎたら録画が自動的に止まります。録画の止め忘れでディスクがいっぱいになるのを防げます。

**録画映像からマウスカーソルを外す**
**録画設定 → マウスカーソル付** をオフにすると、映像にカーソルが映りません。キャプチャー用の **キャプチャー設定 → マウスカーソル付** とは別に設定できるので、画像にはカーソルを入れず録画には入れる、といった使い方ができます。

**画像内の文字をテキストにする**
**保存形式** を **TXT** にすると、横に認識言語の欄が表示されます。文字の言語を選んでキャプチャーすると、画面の文字を読み取ってテキストファイル(`K-001.txt`)に保存します。コピーできない文書や画像内の文字を移すときに便利です。**ドラッグ** と組み合わせれば、必要な段落だけを選んで認識できます。言語一覧は Windows にインストールされている文字認識の言語です。

**キャプチャーをすぐほかの場所に貼り付ける**
**保存形式** を **クリップボード** にすると、ファイルを作らずクリップボードにだけコピーするので、メッセンジャーや文書に `Ctrl`+`V` ですぐ貼り付けられます。ファイルにも残しつつ貼り付けもしたいときは **キャプチャー設定 → クリップボードも** をオンにしてください。どの形式で保存しても、クリップボードにも一緒にコピーされます。

**キャプチャーした画面をリンクで共有する**
**保存形式** を **Imgboxをアップロード** にしてキャプチャーすると、画像がウェブにアップロードされ、その画像ページがブラウザで開きます。アドレスをコピーして送れば、ファイルを添付しなくてもキャプチャーを共有できます。

**キャプチャーしてすぐ印刷する**
**保存形式** を **プリンター** にすると、キャプチャーした画面が既定のプリンターですぐに印刷されます。

**キャプチャーした画像を画面に浮かべて参考にする**
**保存形式** を **フローティング** にしてキャプチャーすると、キャプチャーしたその場所に同じサイズの画像がほかのウィンドウより常に手前に表示されます。ドラッグで動かせるので、値を書き写したり 2 つの画面を比べたりするときに便利です。画像を右クリック → **画像を保存** で PNG · JPG · GIF · BMP · WebP ファイルとして保存し、**フローティングの削除** · **すべてのフローティングを削除** で閉じます。

**ファイルサイズを小さくしたいとき**
**保存形式** を **JPG** か **WebP** にして、横の画質欄で 100 · 90 · 80 · 70 · 60 から選びます(最初は 90)。数字が小さいほどファイルは小さくなります。文字の多い画面には PNG、写真の多い画面には JPG · WebP が向いています。

**ファイル名の付け方を変える**
**ファイル名設定** で選びます。
- **自動インクリメント番号 #1**(初期設定) — 保存フォルダの一番大きい番号の次から続けて保存します(`K-001`、`K-002` …)。
- **自動インクリメント番号 #2** — 空いている一番小さい番号から埋めます。途中のファイルを削除した場合、その番号がまた使われます。
- **日付時刻** — キャプチャーした時刻で名前を付けます(`K-20260928-153012345`)。何日分ものキャプチャーを時間順に整理するときに便利です。

どの方法でも、同じ名前のファイルがあれば上書きせず、新しい名前で保存します。

**保存フォルダを変える**
**保存フォルダ設定** で好きなフォルダを選びます。最初はデスクトップです。メニューの **開いたフォルダ**(またはウィンドウの **開いたフォルダ**)でいつでもそのフォルダを開けます。

**ホットキーを変える**
**ショートカットキー設定** で `Ctrl` · `Alt` · `Shift` にチェックを入れてキーを選び、**オーケー** を押します。キーは `PrintScreen`、`A` ~ `Z`、`0` ~ `9`、`F1` ~ `F12`、`DEL` から選べます。ほかのプログラムがすでに使っている組み合わせの場合は知らせてくれるので、別の組み合わせを選んでください。

**`PrintScreen` で Windows の Snipping Tool が開くとき**
Windows 11 には `PrintScreen` を押すと Snipping Tool が開く設定があります。Kalmuri は起動時にこの設定をオフにして、`PrintScreen` が Kalmuri で動くようにします。

**キャプチャー音を変える**
**キャプチャー設定 → キャプチャー音** で **なし** · **キャプチャー前の音**(初期設定) · **キャプチャー·フーの音** を選びます。静かな場所では **なし**、保存が終わったことを音で確認したいときは **キャプチャー·フーの音** が便利です。

**キャプチャーにマウスカーソルを入れる・外す**
**キャプチャー設定 → マウスカーソル付** をオンにすると(初期設定)、キャプチャーにカーソルも写ります。ボタンの位置を指し示す説明図ではオンに、すっきりした画面が必要ならオフにしてください。

**Windows の起動時に自動で準備しておく**
**システム起動時に実行** をオンにすると、Windows の起動時に Kalmuri がウィンドウを出さずにタスクトレイで始まり、すぐにホットキーでキャプチャーできます。インストーラー版は最初からオンになっています。

**ウィンドウを閉じても使い続ける・完全に終了する**
ウィンドウの X は Kalmuri を終了するのではなく、タスクトレイに隠すだけです。完全に終了するには、右クリックメニューの **終了** を押して確認します。録画中は、先に録画を止めてから終了してください。

**表示言語を変える**
**言語設定** で 한국어 · English · 日本語 · 中文 · Русский · Italiano · Français · Español から選ぶと、すぐに切り替わります。

### 著作権について

Kalmuri でキャプチャー・録画する画面には、他人の文章・画像・映像・音楽が含まれている場合があります。個人的な保管や参考の範囲を超えて共有・公開するときは権利者の許可が必要な場合があるので、各サービスの利用規約と著作権法を守ってください。

## 設定

すべての設定は変更するとすぐに保存され、次回の起動でもそのまま使われます。

| 項目 | 初期値 |
|---|---|
| キャプチャー | フルスクリーン |
| 保存形式 | PNG |

- **TXT**(文字認識)は Windows にインストールされている文字認識の言語を使います。
- インターネット接続は、新しいバージョンの案内、**Imgboxをアップロード**、**ウェブブラウザ** キャプチャーにだけ使います。

## アップデート

Kalmuri は自動では更新 **しません**。起動時に新しいバージョンがあるか確認して案内ウィンドウを表示し、**[はい]** を押すとダウンロードページを開いてプログラムを閉じます。新しいバージョンは内部検証の後に手動で配布され、[Kalmuri のページ](https://kilho.net/kalmuri)で告知されます。[アップデートポリシーのお知らせ](https://en.kilho.net/archives/notice/2940)を参照してください。
